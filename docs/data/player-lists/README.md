# Player Lists

These CSV files are used as name-only player filters on the Ranking page.

Edit `japan-representative-squad.csv` directly in GitHub to maintain a squad list.

Required format:

```csv
player_name
Shuhei Takeuchi
Lachlan Boshier
```

Matching is based on player name only. The app normalizes case, full-width/half-width characters, spaces, and punctuation before comparing names.
